## 💡 Development Process

- Used **component-based CSS** for consistency
- Product data handled via `data-*` attributes and **JavaScript**
- Tested across multiple screen sizes using **DevTools**
- **AI tools** like ChatGPT helped with debugging, layout structure, and writing clean commit messages

## 💬 Final Reflections

**How did I manage the projects?**  
Using a **branch-per-feature** Git flow and setting consistent daily goals.

**How did I solve problems?**  
By breaking issues into steps, using **DevTools**, and consulting **ChatGPT**.

**Time management?**  
Scheduled focused 2-hour coding blocks and avoided multitasking.

**Hardest part?**  
Getting mobile layout and modal spacing right — solved with media queries and hands-on device testing.

**Stress management?**  
Kept commits small, focused on one task at a time, and took short breaks to reset.

**Use of AI tools?**  
A huge help — from generating CSS snippets and layout ideas to debugging and boosting productivity.
